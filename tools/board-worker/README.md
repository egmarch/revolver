# Общая доска REVOLVER (Cloudflare Worker)

Рисунок баллончиком на белой доске в подкастной сохраняется для всех посетителей.
Без воркера доска работает локально: рисунок остаётся только в браузере того, кто рисовал.

## Включить (5 минут, бесплатный тариф Cloudflare)
1. `npm i -g wrangler` и `wrangler login`.
2. `cd tools/board-worker`, затем `wrangler kv namespace create BOARD` и вставьте выданный `id` в `wrangler.toml`.
3. `wrangler secret put ADMIN_KEY`: придумайте длинный пароль для очистки доски.
4. `wrangler deploy`: получите адрес вида `https://revolver-board.<аккаунт>.workers.dev`.
5. В `studio3d-src/src/board.js` впишите `BOARD_ENDPOINT = 'https://revolver-board.<аккаунт>.workers.dev/board'`,
   пересоберите (`cd studio3d-src && npm run build`) и опубликуйте.

## Очистить доску (если нарисовали лишнее)
`curl -X DELETE https://revolver-board.<аккаунт>.workers.dev/board -H "x-admin-key: ВАШ_ПАРОЛЬ"`

## Ограничения (защита от спама и лимитов)
- Не больше 600 точек за запрос и 1 запрос в 4 секунды с одного IP; на доске хранится до 30 000 последних точек.
- Принимаются только числа в пределах доски; разрешены 5 цветов палитры.
- Бесплатный KV: 1000 записей в день. Клиент отправляет рисунок пачками (раз в 15 с и при закрытии вкладки), этого хватает на несколько сотен рисующих посетителей в день. Если трафик вырастет, переведите хранилище на Durable Object или D1.
- Список разрешённых сайтов задан в `ORIGINS` в `index.js`.
